# BoleiaISEP – página do projeto

Equipa Noddy · Laboratório de Projeto 1 · ISEP

## Como abrir
Abrir o ficheiro index.html no browser. Precisa de internet só para carregar o Bootstrap.

## Ficheiros
- src/ – o HTML dividido por secção (problema, vantagens, ods, equipa, ...)
- css/partes/ – o CSS dividido por secção
- build.py – junta os ficheiros de src/ e css/partes/ no index.html e no css/style.css
- index.html e css/style.css – resultado final (é o que o browser abre)
- js/preco.js – simulador de preço
- img/ – logótipos, imagens dos ODS e fotos da equipa

## Como editar
1. Alterar o ficheiro da secção em src/ (ou css/partes/).
2. Abrir o terminal na pasta do projeto e correr python build.py.
3. Abrir (ou atualizar) o index.html no browser.

Se se editar o index.html diretamente, a alteração perde-se na próxima vez que se correr o build.py.
